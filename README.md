# ETF 策略台

采用方案②原版，按已完成交易日计算指数、次日开盘参考计划。自动模拟账户从首次部署后的可执行开盘开始，实际交易由用户在富途执行。

## 启用

1. 将仓库设为公开以使用免费 GitHub Pages。
2. 在 Settings → Secrets and variables → Actions 添加 DESK_PASSWORD；使用交付给账户所有者的私密密码文件。不要将密码写入代码或提交历史。
3. 在 Settings → Pages 将 Source 设为 GitHub Actions。
4. 在 Actions 手动运行 Daily ETF desk。成功后网址为 https://53wusan.github.io/ETF-0718-Strategy/ 。此地址只有发布成功后才可访问。

页面在浏览器中解密 AES-GCM 数据，密码不存入浏览器持久存储。账户配置与账本在仓库中仅保存密文，自动任务通过 GitHub Secret 解密、计算并重新加密。

每日定时为 UTC 23:47 周一至周五（北京时间周二至周六07:47），GitHub调度可能延迟。数据过期时网页停止提供买卖计划。

模拟费用暂为单边0.1%，使用可分割复权份额；实际整数股、成交价与富途费用通过版本对账确认。不会自动连接券商或写入虚构的实际成交。

旧项目文件已从当前文件树替换；历史提交是否清除以实际提交说明为准。代码与历史行情公开，个人账户数据加密。
